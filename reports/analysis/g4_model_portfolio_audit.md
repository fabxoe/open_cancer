## 검증 범위

- 모든 OOF는 ID·정답·fold·26개 확률 열과 확률 합을 검증했습니다.
- 모든 test 확률은 행 수·확률 범위·ID 순서를 검증했습니다.
- pairwise 결과에는 라벨 불일치, 오류 상태 Pearson, 확률 Pearson/Spearman을 기록했습니다.
- test 분포, Public LB 점수, 제출 결과는 선택 기준으로 사용하지 않았습니다.

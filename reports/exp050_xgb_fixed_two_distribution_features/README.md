# EXP-050: EXP-005 + 반복 선택 파생변수 2종 고정 검증

## 목적

EXP-045의 nested permutation 분석에서 비교적 강하고 안정적으로 반복 선택된
다음 두 피처를 실행 전에 고정하고, EXP-005 기본 피처에 추가했을 때 OOF Macro
F1이 개선되는지 한 번 검증했다.

- `sample__synonymous_gene_count`: synonymous 변이가 관찰된 유전자 수
- `sample__variants_per_mutated_gene_mean`: 변이 유전자 하나당 평균 변이 수

EXP-005의 유전자×변이유형 희소 피처, XGBoost 파라미터, balanced sample
weight와 공용 5-fold는 그대로 유지했다. 추가 피처 선택·모델 튜닝·외부
데이터·앙상블·후처리는 사용하지 않았다.

## 검증상 주의

두 피처는 같은 공용 split을 사용한 EXP-045 분석에서 도출됐다. 따라서 이번
실험은 완전히 독립적인 확인이 아니라, 피처 목록을 실행 전에 고정한 후속
ablation이다. 작은 점수 상승만으로 일반화 성능 개선을 확정하지 않으며,
실행 결과를 본 뒤 같은 Issue에서 피처를 다시 빼거나 교체하지 않았다.

## 해석

EXP-043의 28개 전체 사용과 EXP-045의 fold별 자동 선택보다는 나았지만, 두
피처를 고정해도 EXP-005의 성능을 회복하지 못했다. permutation 분석에서
반복 선택됐다는 것은 모델이 해당 피처를 사용했다는 정황이지, EXP-005에
추가했을 때 독립적인 성능 향상을 보장한다는 뜻은 아니었다.

두 피처는 기존 유전자×변이유형 피처와 상관된 정보를 다시 요약했을 가능성이
있으며, 이 경우 XGBoost가 기존 피처만으로 이미 유사한 구분을 학습할 수 있다.
따라서 EXP-050 구성은 미채택하고 EXP-005를 안정적인 비교 기준으로 유지한다.

이후 피처 실험은 기존 정보를 재집계하는 변이량 요약보다, EXP-005에 없던
정확한 단백질 위치·hotspot처럼 새로운 정보 단위를 추가하는 방향을 우선한다.

# EXP-043: EXP-005 + 샘플 변이분포 확장 피처

## 요약

EXP-005의 모델·유전자×변이유형 희소 피처·공용 split을 유지하고, EXP-033의
log burden 3개와 신규 샘플 변이분포 통계 25개를 추가했다. 모델 튜닝, 앙상블,
외부 데이터와 피처 선택은 수행하지 않았다.

## 내부 검증 결과

| 항목 | EXP-005 | EXP-033 | EXP-043 |
|---|---:|---:|---:|
| 전체 OOF Macro F1 | 0.4043796587 | 0.4057244634 | 0.3989124897 |
| fold 평균 | 0.4028662325 | 0.4046139109 | 0.3979052545 |
| fold 표준편차 | 0.0086812077 | 0.0109735092 | 0.0040939951 |
| Accuracy | 0.3965489437 | 0.3981615868 | 0.3931623932 |
| Log Loss | 1.8632071018 | 1.8625637293 | 1.8917084932 |

EXP-043은 EXP-033보다 OOF가 `0.0068119737`, EXP-005보다 `0.0054671690`
낮았다. fold 간 편차는 감소했지만 평균 성능과 Log Loss가 모두 나빠졌으므로,
28개 확장 피처를 전부 사용하는 구성은 채택하지 않는다.

## 추가 피처 사용 관찰

저장된 5개 fold 모델에서 28개 추가 피처 중 27개가 모든 fold에서 split에
사용됐고, `complex_gene_count_log1p`만 2개 fold에서 사용됐다. gain 상위에는
다음 피처가 있었다.

| 피처 | fold별 gain 평균 |
|---|---:|
| 전체 변이 수 log1p | 6.5645 |
| 변이 유전자 수 log1p | 5.1166 |
| synonymous 영향 유전자 수 | 3.9696 |
| 유전자별 최대 변이 수 | 3.8744 |
| 단일 변이 유전자 수 | 3.8197 |

gain이 높다는 것은 모델이 해당 피처를 자주 유용한 분기로 사용했다는 뜻이지만,
그 피처가 OOF 개선에 기여했다는 증거는 아니다. 중요도만 보고 전체 train에서
피처를 고른 뒤 같은 OOF로 재평가하면 선택 편향이 생길 수 있다.

train/test 평균 차이는 일반화 위험을 확인하는 진단으로만 사용했다. 프로젝트
규칙에 따라 test 분포를 공식 피처 선택 기준으로 사용하지 않는다.

## 다음 피처 선택 방법

후속 실험은 EXP-005 기본 피처를 항상 유지하고 28개 파생변수만 선택 대상으로
삼는다. 각 outer fold마다 다음 절차를 독립적으로 수행해야 한다.

1. outer train 안에서만 inner 3-fold를 만든다.
2. 각 inner train으로 모델을 학습한다.
3. inner validation에서 파생변수별 permutation Macro F1 감소량을 계산한다.
4. 3개 inner fold 중 2개 이상에서 감소량이 양수이고 중앙값이 0보다 큰 피처만
   선택한다.
5. 선택된 피처로 outer train 모델을 다시 학습해 outer validation을 예측한다.
6. outer fold별 선택 목록과 선택 빈도를 resolved config와 보고서에 기록한다.

이 방식은 모델 설정을 튜닝하지 않고도 “그 피처를 섞었을 때 실제 검증 점수가
반복해서 나빠지는가”를 직접 확인할 수 있다. outer validation은 선택 과정에
사용하지 않으므로 최종 OOF도 비교 가능한 상태로 유지된다.

# EXP-240 암종별 분자 변이조합 피처

## 결론

EXP-229에 공개 TCGA 문헌에서 사전에 고정한 7개 암종 관련 유전자 모듈의
조합 피처 21개를 추가했지만, OOF Macro F1은 **0.4189644465**로 부모보다
`-0.0040241280` 하락했습니다. Log Loss도 `+0.0908827782` 악화되어 전체
피처 묶음은 **ARCHIVE**합니다.

다만 fold 표준편차는 `-0.0022967677` 개선됐고 LGG `+0.0778134212`,
KIRC `+0.0686430978`, LAML `+0.0229335882` 등 일부 클래스의 양의 변화가
관찰됐습니다. 모든 모듈을 동시에 추가한 실험이므로 특정 모듈의 인과적 효과로
해석하지 않고, 후속 실험에서는 단순 개수 대신 활성화형·기능소실형 변이를
구분한 별도 문헌 고정 피처를 검증합니다.

## 무엇을 추가했나

7개 문헌 고정 모듈마다 다음 3개 값을 계산했습니다.

- 모듈 안에서 변이된 유전자 수
- 서로 다른 유전자가 2개 이상 변이됐는지
- 핵심 유전자와 partner 유전자가 함께 변이됐는지

대상 모듈은 신경교종 2종, 대장암, 폐선암, 자궁내막암, 급성골수성백혈병,
피부흑색종입니다. 최초 신장암 후보는 대회 패널에서 `VHL`의 partner 유전자가
모두 빠져 있어 공식 실행 전에 제외했습니다.

문헌은 고정 유전자 그룹·관계 정의에만 사용했습니다. 외부 환자 데이터,
SUBCLASS, train label, 관측 빈도, test 분포 및 Public LB는 피처 정의에
사용하지 않았고, 각 샘플의 값은 대회 CSV에서만 계산했습니다.

## 해석과 한계

- 암종 관련 유전자들을 묶는 것만으로 모든 클래스가 안정적으로 좋아지지는 않았습니다.
- 여러 모듈을 한꺼번에 추가했으므로 클래스별 변화와 개별 모듈을 직접 연결할 수 없습니다.
- KIRC는 전용 모듈을 제외했는데도 개선되어, 모델 결정 경계의 간접 변화도 섞였음을
  보여줍니다.
- 따라서 이 결과를 근거로 canonical OOF에서 유리한 모듈만 고정 선택하지 않습니다.
